# Configuración de datos

`application.json` registra la edición metodológica solicitada y el estado de
los parámetros específicos de jurisdicción. No almacena valores HCM ni
parámetros ecuatorianos en esta fase.

Las futuras adaptaciones de Ecuador deben mantenerse separadas en esta carpeta,
con fuente, unidades, jurisdicción, vigencia y revisión documentadas. No deben
sobrescribir tablas del HCM 2000.
