# Documentos de referencia proporcionados

- `Capacidad_NDS_1.pdf`: material académico de PUCE para definiciones,
  clasificación HCM de carreteras de dos carriles y conceptos de tránsito.
- `C05-C07-Capacidad_2.pdf`: material académico de PUCE con el procedimiento
  resumido para dos carriles y las tablas/ecuaciones resumidas de segmento
  general multicarril.

Las tablas multicarril transcritas en `../hcm_tables/reviewed/multilane_design_tables.json`
se etiquetan como fuente secundaria pendiente de cotejo independiente con el
HCM 2000 original. La aplicación conserva esta limitación en la verificación y
en las advertencias del cálculo.
